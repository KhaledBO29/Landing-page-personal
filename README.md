# Khaled — Personal Hub

Landing page mobile-first para el portafolio, ventures y contacto directo de
Khaled Benavides. Construida con Next.js App Router, TypeScript, Tailwind CSS y
Lucide.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Los perfiles, proyectos y el número de WhatsApp se editan en
`src/config/site.ts`.

Para validar tipos antes de publicar, ejecuta `npm run typecheck`; para generar
la versión optimizada, ejecuta `npm run build`.
